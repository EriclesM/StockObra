# ObraStock

Sistema web responsivo de controle de estoque desenvolvido para uma construtora e comércio local. Funciona em smartphones e computadores, registra o usuário responsável e gera relatórios por obra.

## O que o sistema faz

- Cadastro e login de usuários por e-mail e senha;
- cadastro de clientes, obras e produtos;
- entrada de produtos com fornecedor, quantidade, valor e data;
- saída de produtos com obra opcional, usuário responsável, quantidade e valores;
- saldo atualizado automaticamente e bloqueio de saída maior que o estoque disponível;
- alerta visual de estoque mínimo;
- histórico completo das movimentações;
- relatório filtrado por obra e período;
- exportação do relatório em CSV e versão para impressão/PDF;
- layout adaptado para smartphone e computador;
- instalação como aplicativo (PWA) pelo navegador.
